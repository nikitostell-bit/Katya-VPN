# Katya VPN 🚀

**Katya VPN** — это быстрое и безопасное приложение для обхода блокировок.
Работает на базе протоколов Xray/VLESS.

## 🛠 Установка сервера
1. Арендуйте VPS (Ubuntu 20.04/22.04).
2. Используйте готовый скрипт установки:
   ```bash
   bash <(curl -Ls https://githubusercontent.com)
   ```

## 📱 Клиентская часть
* **Android:** В разработке (Kotlin).
* **iOS:** В планах.
